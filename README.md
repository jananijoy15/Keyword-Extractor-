🔑 Keyword Extractor

Keyword Extractor is a simple web-based Text Analysis application that identifies the most frequently occurring and important words from the given text.

Live Application Link 
https://jananijoy15.github.io/Keyword-Extractor-/

✨ Features

- 📝 Enter or paste text
- 🔍 Extract important keywords
- 📊 Count total words
- 🔢 Display number of keywords
- 📌 Show keywords as separate tags
- ⚡ Fast text processing using JavaScript
- 📱 Mobile-friendly responsive interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How to Use

1. Open the application in a web browser.
2. Enter or paste a paragraph into the text box.
3. Click the Extract Keywords button.
4. The application removes common words.
5. Frequently occurring keywords are displayed as results.

💡 Example

Input:

Artificial Intelligence is changing technology.
Artificial Intelligence is used in healthcare.
Technology and Artificial Intelligence are growing rapidly.

Output:

Artificial
Intelligence
Technology
Healthcare
Growing

📊 Analysis

The application provides:

Feature| Description
Total Words| Number of words in the input
Keyword Count| Number of important keywords detected
Keywords| Frequently occurring meaningful words
